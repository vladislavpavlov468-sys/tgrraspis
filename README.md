# Дневник — MVP

Первый этап веб-приложения персонального дневника студента для группы ТГР-26-1.

## Запуск

Откройте `index.html` в браузере. Для локального сервера можно использовать любой статический сервер.

В текущем MVP доступны рабочие экраны главной страницы, расписания, календаря, заданий, оценок и учебных долгов. Задания сохраняются в `localStorage` браузера.

Расписание внесено только после подтверждения исходной таблицы пользователем. Данные PDF и изображения не изменялись.

## Запуск на компьютере и телефоне

Сейчас локальный сервер слушает все сетевые интерфейсы компьютера:

- на компьютере: http://127.0.0.1:4173/
- на телефоне в той же Wi-Fi сети: http://192.168.1.102:4173/

На телефоне можно открыть меню браузера и выбрать «Добавить на главный экран». На компьютере поддерживаемый браузер может предложить установить приложение как отдельное окно.

Это локальный запуск, а не публичный интернет-адрес. Для публикации в интернете позже понадобятся домен, HTTPS и хостинг.
